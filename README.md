# Big Data Analytics: coursework notebooks

Nine in-class programming exercises (ICPs) from my big data analytics course, written as Google Colab notebooks. They progress from Python fundamentals to data analysis and deep learning.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?logo=tensorflow&logoColor=white) ![Keras](https://img.shields.io/badge/Keras-D00000?logo=keras&logoColor=white)

| Notebook | Focus | Libraries |
|---|---|---|
| ICP1 to ICP3 | Python fundamentals: collections, statistics, NumPy arrays | NumPy, collections, statistics |
| ICP4 | Data loading and visualization | pandas, Matplotlib |
| ICP5 | Exploratory analysis and modeling | pandas, scikit-learn, seaborn |
| ICP6 | Neural network on tabular data | Keras, scikit-learn |
| ICP7 | Deep learning with TensorFlow | TensorFlow, Matplotlib |
| ICP8 | Denoising autoencoder | Keras, TensorFlow |
| ICP9 | Keras models wrapped for scikit-learn pipelines | Keras, SciKeras |

Open any notebook in Colab with the badge at the top of the file.
